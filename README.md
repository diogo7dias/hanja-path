# Hanja Path

**Live site:** [diogo7dias.github.io/hanja-path](https://diogo7dias.github.io/hanja-path/)

Hanja Path is a minimal study companion for Korean learners who want to understand and remember Sino-Korean vocabulary through hanja.

## Features

- 1,795 education hanja organized into Beginner, Intermediate, and Advanced levels
- Hanja cards with Korean readings, meanings, and memory tips
- Three-word vocabulary examples with hanja breakdowns and English glosses
- Search and pagination across each level
- Individual study pages for every hanja character
- Korean example sentences to connect vocabulary with real usage
- Responsive, distraction-free dark editorial design
- Ko-fi support link for the project

The site is a static HTML/CSS/JavaScript website and is hosted with GitHub Pages.
